#  Cortexa AI - Smart Assistant & IoT Platform

Cortexa is an advanced, privacy-first AI smart assistant platform designed for seamless IoT device control, automated daily scheduling, and real-time cybersecurity briefings. It features a striking royal blue UI theme, responsive multi-page architecture, and cross-platform desktop support.

Developed by **Daniyal Saleem**.

---

##  Project Purpose

The primary goal of Cortexa is to bridge the gap between AI automation and daily practical utility. It serves as a centralized hub that combines:
* **Smart Home/Office Automation:** Managing IoT devices efficiently.
* **Productivity & Scheduling:** Handling daily tasks, reminders, and schedules seamlessly.
* **Security Awareness:** Delivering real-time threat intelligence and security status briefings to keep users informed.

---

##  How It Works (Architecture & Workflow)

Cortexa is built using a modern decoupled monorepo architecture, ensuring high performance, modularity, and smooth cross-platform execution:

1. **Frontend Interface (Next.js & Tailwind CSS):**
   * Provides a clean, modern, and responsive user dashboard featuring a professional royal blue theme.
   * Handles user interactions, real-time chat displays, and control panels for IoT and scheduling.

2. **Backend Engine (FastAPI & Python):**
   * Acts as the core processing unit, managing API endpoints, AI prompt handling, and business logic.
   * Processes backend requests securely and runs automated scripts/testing modules.

3. **Desktop Integration (Tauri):**
   * Wraps the web application into a lightweight, native desktop environment for Windows and Linux, enabling true local execution and low resource consumption.

4. **Data & Memory Management:**
   * Utilizes local state and structured storage logs to maintain persistent context, user settings, and historical interaction data.
